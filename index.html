Find quick answers about using the LUMORA demo.

How do I save a title?

Select the plus button on any title card. It will be saved to My List on this browser.

Does LUMORA create a real account?

No. The sign-in form is a front-end demonstration only. It does not create accounts or send or store credentials.

Why might a trailer not play?

Trailers are embedded from YouTube. They will not play if the site is opened directly from a folder (file://) — use a web server or the hosted link. If a video still fails, use the “Open trailer on YouTube” link under the player.
